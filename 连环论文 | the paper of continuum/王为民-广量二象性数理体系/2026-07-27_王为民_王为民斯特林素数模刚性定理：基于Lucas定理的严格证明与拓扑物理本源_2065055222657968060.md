一、预备知识

1.1 第二类斯特林数的定义与显式表达式

第二类斯特林数 S(n,k) 表征将 n 个不同元素划分为 k 个非空无序集合的方案总数，满足递推关系：

S(n,k) = kS(n-1,k) + S(n-1,k-1)

边界条件为 S(n,1)=1、S(n,n)=1，当 k>n 时 S(n,k)=0。

由容斥原理可导出其显式闭式表达式，是本次证明的核心代数载体：

S(n,k) = \frac{1}{k!}\sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j^n

1.2 Lucas 定理正式表述

Lucas定理是素数模下二项式系数的经典核心计算定理，其严格表述为：

设 p 为素数，将非负整数 m、n 展开为 p 进制形式：

m = m_0 + m_1 p + m_2 p^2 + \dots + m_r p^r \\

n = n_0 + n_1 p + n_2 p^2 + \dots + n_r p^r

其中 0 \le m_i, n_i < p，则二项式系数满足同余关系：

\binom{m}{n} \equiv \prod_{i=0}^r \binom{m_i}{n_i} \pmod{p}

约定当 n_i > m_i 时，\binom{m_i}{n_i}=0。

二、基于Lucas定理的前置引理推导

引理1：素数阶二项式系数的整除性质

命题：设 p 为素数，对任意整数 0<j<p，恒有

\binom{p}{j} \equiv 0 \pmod{p}

证明：

将 p 与 j 表示为 p 进制形式：

- p 的 p 进制为 (1,0)_p，即高位 m_1=1，低位 m_0=0；

- 因 0<j<p，j 的 p 进制为 (0,j)_p，即高位 n_1=0，低位 n_0=j。

代入Lucas定理：

\binom{p}{j} \equiv \binom{1}{0} \cdot \binom{0}{j} \pmod{p}

由于 j>0，低位项 \binom{0}{j}=0，因此：

\binom{p}{j} \equiv 1 \times 0 = 0 \pmod{p}

证毕。

引理2：费马小定理（Lucas定理的直接推论）

命题：设 p 为素数，对任意整数 a，恒有

a^p \equiv a \pmod{p}

证明：

采用数学归纳法结合引理1推导。

1. 基例：当 a=0、a=1 时，等式显然成立。

2. 归纳假设：假设当 a=k 时结论成立，即 k^p \equiv k \pmod{p}。

3. 归纳递推：考虑 a=k+1，由二项式定理展开：

(k+1)^p = \sum_{j=0}^p \binom{p}{j} k^j

根据引理1，对所有 0<j<p，\binom{p}{j} \equiv 0 \pmod{p}，因此展开式仅首尾两项留存：

(k+1)^p \equiv \binom{p}{0}k^0 + \binom{p}{p}k^p = 1 + k^p \pmod{p}

代入归纳假设 k^p \equiv k，得：

(k+1)^p \equiv 1 + k = (k+1) \pmod{p}

由数学归纳法，结论对所有非负整数成立；负整数情形可由奇偶对称性直接推广。证毕。

三、王为民斯特林素数模刚性定理：主定理与严格证明

3.1 定理正式表述

王为民斯特林素数模刚性定理：设 p 为素数，对任意整数 k 满足 1<k<p，恒有：

\boxed{S(p,k) \equiv 0 \pmod{p}}

3.2 严格代数证明

证明：由第二类斯特林数的显式闭式，代入 n=p 得：

S(p,k) = \frac{1}{k!}\sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j^p

步骤1：可逆性说明

因 1<k<p 且 p 为素数，k! 的所有素因子均小于 p，故 k! 与 p 互素，k! 在模 p 整数环中存在乘法逆元。因此 S(p,k) \equiv 0 \pmod{p} 等价于分子求和式模 p 为0：

\sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j^p \equiv 0 \pmod{p}

步骤2：代入费马小定理化简

由引理2（Lucas定理推论），对任意 j \le k < p，有 j^p \equiv j \pmod{p}，代入求和式得：

\sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j^p \equiv \sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j \pmod{p}

步骤3：求和式的斯特林数对应

观察右侧求和式，其结构恰好对应 n=1 时的斯特林数显式公式：

S(1,k) = \frac{1}{k!}\sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j^1

因此求和式可改写为：

\sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j = k! \cdot S(1,k)

根据第二类斯特林数的组合定义，将1个元素划分为 k>1 个非空集合的方案数为0，即 S(1,k)=0。代入得：

\sum_{j=0}^k (-1)^{k-j} \binom{k}{j} j = k! \times 0 = 0

步骤4：结论合并

综上，分子求和式模 p 恒为0，结合 k! 模 p 可逆，最终得：

S(p,k) \equiv 0 \pmod{p}

证毕。

3.3 王为民循环轨道组合佐证

从计数本质出发，可通过王为民循环轨道构造对定理给出直观的组合化印证：

对 p 个元素的所有 k 分拆，定义元素的循环置换操作 \sigma：将编号 0,1,\dots,p-1 的元素轮换映射为 1,2,\dots,p-1,0。

- 因 p 为素数，任意分拆在 \sigma 作用下的轨道长度只能是1或 p；

- 轨道长度为1当且仅当分拆在轮换下完全不变，仅对应 k=1（所有元素同集）与 k=p（每个元素单独成集）两种平凡情形；

- 当 1<k<p 时，不存在长度为1的轨道，所有分拆都属于大小为 p 的轨道，因此分拆总数必为 p 的整数倍。

组合论证与代数证明完全自洽，为王为民斯特林素数模刚性定理提供了清晰的计数图景。
