3 王为民数域临界线定理

3.1 定理表述

定理3.1（王为民数域临界线定理）

上。该结论为无条件严格定理。

3.2 反证法完整证明

步骤1：反设

假设存在一个非平凡零点

\rho = \sigma + it

满足\sigma \neq 1/2，不妨设\sigma > 1/2（\sigma < 1/2情形由对称性同理可得）。

步骤2：对称约化

由王为民数域泛函方程定理，若\rho是零点，则其关于临界线的对称点

1-\rho = (1-\sigma) - it

也必然是零点。因此，偏离临界线的零点以对称对的形式成对出现，二者恰好构成一对标准扰动零点对，偏移量为

\Delta = \sigma - \frac{1}{2} > 0

步骤3：扰动模型

将这对偏离零点视为临界线上基准零点\rho_0 = 1/2 + it受到扰动后的结果，对应的扰动因子为有理函数形式，扰动后的谱系数满足

\tilde{b}_m^{(K)} = b_m^{(K)} + \delta b_m(\Delta)

其中\delta b_m(\Delta)为扰动项，与第一百一十九篇给出的形式一致。

步骤4：应用全局符号反转定理

根据王为民数域全局符号反转定理，由于\Delta > 0，必然存在某一阶m_0，使得扰动后的系数变为负值，即

\tilde{b}_{m_0}^{(K)} < 0

步骤5：应用全正变换定理

另一方面，王为民数域ξ函数的谱系数来自素理想指示函数的谱展开。根据王为民数域全正变换定理，所有阶的谱系数必须严格非负，即对所有m有

b_m^{(K)} \ge 0

步骤6：导出矛盾

步骤4的结论与步骤5的约束形成直接矛盾：若存在偏离临界线的零点，则必然打破全正性约束，出现负系数；而全正变换定理要求谱系数必须全部非负。

步骤7：结论

反设不成立。因此，不存在实部不等于1/2的非平凡零点，即所有非平凡零点均位于临界线\text{Re}(s)=1/2上。

本证明不存在循环论证风险，核心依据是三大前置定理均独立于“零点在临界线上”的结论：
