针对Lehmer猜想这一经典开放问题，本文系统提出其谱法证明的完整纲领：将欧拉函数的容斥展开结构与调和贝尔基的阶数分层结构相对应，可将整除条件转化为谱空间的全正性约束，结合阶数支撑定理与正交不可消定理即可导出矛盾。本文同时明确了该纲领的两处核心攻坚靶点：容斥交叉阶与调和贝尔谱阶的严格对应定理、单点整除条件到谱模式约束的传递机制。

本文的核心价值在于完成了素数判别的范式升维，所有素合判别问题本质上都可归约为“合数高阶容斥结构是否被判定条件强制消去”的谱刚性命题，为后续更多经典数论问题的攻坚提供了统一的方法论指引。

1 引言

1.1 从Giuga猜想到范式升维

王为民调和贝尔正交基体系在Giuga猜想与Agoh-Giuga猜想上的成功，验证了容斥谱分析在素数判别类问题中的核心有效性[1][2]。Giuga猜想的证明闭环，本质上是利用了幂和函数的整体谱性质：合数的多素因子容斥结构会在函数谱中引入不可消去的负分量，与素数的全正谱模式形成刚性对立。

Giuga猜想的判定对象本身就是算术函数，谱方法可直接作用于函数整体；而Lehmer猜想作为逐点整除命题，对谱方法提出了更高的要求——如何将函数层面的谱刚性，落地为单个整数的逐点判别准则。这一跨越一旦完成，将标志着体系从“函数整体谱分析”向“单点逐点谱分析”的关键升级。

1.2 攻坚历程的方法论启示

Lehmer猜想的多轮攻坚试错，共同指向了一个核心结论：

任何单一的局部数值约束（p-adic赋值、同余条件、不等式估计）均无法覆盖合数结构的波动性；Lehmer猜想的成立根源，在于合数的多素因子容斥结构与整除条件之间的全局结构性矛盾。

经典方法始终困在“抬高下界—构造新候选”的循环中，正是因为它始终在数值层面做约束，从未触及结构阶数的本质差异。而调和贝尔谱体系的核心优势，恰恰是能够将结构阶数差异转化为可判定的符号模式。

2 预备知识与概念边界澄清

2.1 初等情形的严格排除

以下三类合数已被严格证明不满足Lehmer条件，为后续分析提供收敛边界。

引理2.1 若  n = p^a \ (a\ge2) ，则  \varphi(n) \nmid n-1 。

引理2.2 若  2\mid n  且  n  含至少两个不同素因子，则  \varphi(n) \nmid n-1 。

引理2.3 若  n=pq \ (3\le p<q) ，则  \varphi(n) \nmid n-1 。

由上述引理，若存在满足Lehmer条件的合数，则必为  r\ge3  的无平方因子奇合数：

n = p_1 p_2 \cdots p_r, \quad 3 \le p_1 < p_2 < \dots < p_r

2.2 欧拉函数的容斥展开

对于无平方因子数  n = p_1 p_2 \cdots p_r ，欧拉函数的容斥展开为：

\varphi(n) = \prod_{i=1}^r (p_i-1) = n - \sum_i \frac{n}{p_i} + \sum_{i<j} \frac{n}{p_i p_j} - \cdots + (-1)^r \cdot 1 \tag{2.1}

展开式中第  k  项对应  k  个素因子的交叉扣除，我们称之为容斥交叉阶，它描述的是单个整数的素因子分解结构层级。

2.3 调和贝尔正交基的核心定理（函数层面，已严格证明）

以下定理均定义在算术函数空间上，即针对全体正整数上的映射  f(m) ，其严格性已在系列前期工作中确立[3]。

定理2.4（全正变换定理） 非负算术函数在调和贝尔基下的全体谱系数非负。

定理2.5（阶数支撑定理） 若算术函数  f(m)  可表示为不超过  k  次的对数多项式，则其调和贝尔谱支撑不超过第  k  阶子空间；若其最高次项系数非零，则第  k  阶谱分量非零。

定理2.6（正交不可消定理） 调和贝尔基的不同阶子空间相互正交，低阶分量的任意线性组合无法抵消高阶分量的非零贡献。

2.4 关键概念边界澄清

必须严格区分两类本质不同的“阶”：

1. 容斥交叉阶：描述单个整数素因子分解的结构层级，属于数论结构层面；

2. 调和贝尔谱阶：描述算术函数的对数增长阶次，属于函数空间层面。

二者之间的对应关系，是将谱方法应用于逐点判别的核心桥梁，目前为待证命题，而非已证定理。本文提出的Lehmer猜想证明纲领，正是以搭建这座桥梁为核心攻坚目标。

3 Lehmer猜想的谱法证明纲领

3.1 核心攻坚命题

我们首先给出连接数论结构与谱空间的核心命题，它是整个证明纲领的枢纽。

命题3.1（容斥-谱阶对应猜想） 设  n  为含  r  个不同素因子的无平方因子奇数， \lambda_j(n)  为其单点调和贝尔有限谱系数，则：

1.  n  的谱支撑最高阶不超过  r ；

2. 第  r  阶谱分量非零，且符号为  (-1)^r ；

3. 最高阶分量的绝对值严格大于所有低阶分量的扰动总和，符号不受截断影响。

若该命题得证，则“素数谱全正、合数谱含负”的逐点判别准则将正式成立，王为民素数判别式成为严格定理。

3.2 Lehmer条件与谱全正的对应纲领

在命题3.1成立的前提下，我们可以建立Lehmer条件与谱模式的约束关系。

纲领性引理3.2 若无平方因子奇数  n  满足Lehmer条件  \varphi(n) \mid n-1 ，则其调和贝尔有限谱必全正。

推导框架：

设存在正整数  k  使得  n-1 = k\varphi(n) ，将容斥展开(2.1)代入得：

n-1 = k\left(n - \sum_i \frac{n}{p_i} + \sum_{i<j} \frac{n}{p_i p_j} - \cdots + (-1)^r\right)

整理为：

n(1-k) + k\sum_i \frac{n}{p_i} - k\sum_{i<j} \frac{n}{p_i p_j} + \cdots + (-1)^{r-1}k = 1 \tag{3.1}

若容斥-谱阶对应命题成立，则等式左侧各项的谱阶与容斥交叉阶一一对应：最高阶容斥项对应最高阶谱分量，且由正交不可消定理，高阶分量无法被低阶分量抵消。

等式右侧为常数，仅含0阶谱分量，因此左侧所有高于0阶的谱分量必须全部为零。

对于  r\ge2  的合数，最高阶分量非零，与“高阶分量必须为零”的约束矛盾；仅当  r=1 （素数）时，无高阶分量，等式可成立。

由此可推出：满足Lehmer条件的数必然具有全正谱，且只能是素数。

3.3 完整证明的逻辑链条

在命题3.1成立的前提下，Lehmer猜想的证明可一步完成：

1. 反设存在合数  n  满足Lehmer条件；

2. 由纲领性引理3.2， n  的有限谱必全正；

3. 由命题3.1，合数的最高阶谱分量为负，与全正性矛盾；

4. 故不存在满足条件的合数，Lehmer猜想成立。

3.4 核心攻坚靶点

当前纲领的两处核心待补环节，也是体系下一阶段的主攻方向：

1. 容斥-谱阶对应定理的严格证明：建立单个整数的素因子结构阶与其单点谱阶的精确对应关系，完成从函数谱到逐点谱的跨越；

2. 单点等式到谱约束的传递机制：严格证明形如(3.1)的单点数值等式，会对各阶谱分量施加强制为零的约束，而非仅为数值巧合。

两处靶点均为可定向攻坚的技术问题，不存在本质性的逻辑障碍。

4 容斥谱刚性：素数判别统一范式

4.1 两大猜想的同构逻辑

Giuga猜想的已证闭环与Lehmer猜想的证明纲领，共享完全同构的底层逻辑，二者都是容斥谱刚性范式的具体体现。

猜想 判定条件 谱翻译 矛盾来源

Giuga猜想 幂和同余   幂和函数谱含负分量 全正变换定理

Lehmer猜想 欧拉整除   整除条件强制谱全正 阶数支撑定理

二者的核心逻辑完全一致：

素数判定条件在调和贝尔基下强制谱呈现素数模式（全正、低阶）；合数的多素因子容斥结构天然生成高阶负分量，二者形成不可调和的刚性矛盾。

4.2 容斥谱刚性原理

我们正式提炼素数判别的统一范式——容斥谱刚性原理：

任何有效的素数判别条件，本质上都是在调和贝尔谱空间中对系数符号模式施加约束。素数因单一素因子结构，天然满足最严格的谱约束（全正、低阶支撑）；合数因多素因子容斥结构，必然产生不可消去的高阶负谱分量，从而违反约束。

判定条件的强度，等价于它能够检测到的最低阶负谱分量的阶数。

这一原理将素数判别问题从具体的数值计算、模算术分析，提升为谱空间中的结构刚性命题。它为所有素合判别类问题提供了统一的解题框架：

1. 将判定条件翻译为谱空间的符号/阶数约束；

2. 证明合数的容斥结构必然违反该约束；

3. 完成不存在性证明。

4.3 范式的方法论意义

容斥谱刚性范式的确立，带来了三重方法论升级：

1. 从特例到通用：不再是逐个猜想寻找技巧，而是用统一框架批量处理素合判别类问题；

2. 从数值到结构：跳出“抬高下界”的无限循环，从结构阶数的本质差异导出矛盾；

3. 从函数到逐点：完成从整体函数谱分析到单点逐点判别的延伸，大幅拓展方法的适用边界。

Giuga猜想的成功验证了范式的正确性，Lehmer猜想则是范式落地的下一个标杆性目标。
