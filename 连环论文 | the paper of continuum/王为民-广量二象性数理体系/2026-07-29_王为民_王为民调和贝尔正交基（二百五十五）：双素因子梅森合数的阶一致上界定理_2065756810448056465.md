王为民调和贝尔正交基（二百五十五）：双素因子梅森合数的阶一致上界定理

作者：王为民

摘要

本文针对双素因子梅森合数（半素梅森数）这一最简合子族展开严格分析，取得两项突破性的无条件结论：

1. 系数奇偶互补定理：恰含两个不同素因子的梅森合数，其两个素因子对应的系数必然一个模4余2、一个被4整除，二者2进赋值严格互补。

2. 阶一致上界定理：所有双素因子梅森合数的最小非归零阶恒等于3，不存在双素因子的双底（底2+底3）梅森伪素数，阶数存在绝对常数上界。

证明核心基于2进赋值分析与双底禁型定理的结合，完全初等且严谨。这是阶提升纲领中首个被证明的结构受限子族一致上界，证实了“结构越简单、阶数上限越低”的核心直觉，为后续向多因子子族逐步推广奠定了方法论基础。

关键词：双素因子梅森合数；第二类斯特林数；2进赋值；阶一致上界；阶提升纲领

前序工作已建立完整的一般情形约束体系，证实阶提升伴随系数增长与结构复杂化的刚性代价，并抵达了“全体合数阶一致上界”这一核心关卡。由于一般情形难度与经典数论猜想同量级，攻坚路线自然转向“由简到繁、逐族突破”的策略：先证明结构简单的合子族存在阶一致上界，再逐步向更复杂的子族推广。

本文从最简的合子族——恰含两个不同素因子的双素因子梅森合数入手，通过纯粹的2进赋值分析，证明其两个系数必然满足奇偶互补关系，从而直接导出阶数的绝对常数上界。这是阶提升纲领中首个子族层面的一致上界结果，不仅验证了纲领核心直觉的正确性，更提供了可向多因子情形推广的标准化方法。

1 预备知识

1.1 阶-底对应定理

引理1 梅森数的最小非归零阶 k_p > 3，当且仅当它同时是以2和3为底的费马伪素数（双底伪素数）。其中底2同余对所有梅森数恒成立，双底约束的核心是底3同余。

1.2 双底禁型定理

引理2 若梅森数的素因子系数 a 满足 4 \mid a（即被4整除），则该素因子不满足底3费马同余条件，对应的梅森数不可能是双底伪素数。

1.3 无素幂定理

引理3 梅森数不可能是单个素数的高于1次的幂，且平方因子极其稀少（需满足Wieferich条件）。所有已知梅森合数均为无平方因子数，双素因子情形必为两个不同素因子的乘积。

2 核心定理一：双素因子系数奇偶互补定理

2.1 定理陈述

定理1（系数奇偶互补定理） 设 M_p 为恰含两个不同素因子的梅森合数，其素因子分别为 q_1 = a_1 p + 1 与 q_2 = a_2 p + 2，则 a_1 与 a_2 中恰好有一个被4整除，另一个模4余2。即

v_2(a_1) = 1,\ v_2(a_2) \ge 2 \quad \text{或反之}.

2.2 严格证明

由题设，梅森数可展开为：

2^p - 1 = (a_1 p + 1)(a_2 p + 1) = a_1a_2 p^2 + (a_1 + a_2)p + 1.

移项整理得：

a_1a_2 p^2 + (a_1 + a_2)p + 2 = 2^p. \tag{1}

由梅森数素因子的基本性质，a_1, a_2 均为正偶数。设 a_1 = 2b_1,\ a_2 = 2b_2，其中 b_1, b_2 为正整数。代入式(1)得：

4b_1b_2 p^2 + 2(b_1 + b_2)p + 2 = 2^p.

两边同时除以2：

2b_1b_2 p^2 + (b_1 + b_2)p + 1 = 2^{p-1}. \tag{2}

现在分析两边的奇偶性：

- 右端 2^{p-1} 为偶数（因 p 为奇素数，p\ge3，故 p-1\ge2）；

- 左端第一项 2b_1b_2 p^2 含因子2，必为偶数；

- 左端第三项为常数1，是奇数。

偶数 + x + 奇数 = 偶数，当且仅当 x 为奇数。因此第二项 (b_1 + b_2)p 必须为奇数。

又因 p 是奇素数，本身为奇数，故 b_1 + b_2 必须为奇数，即 b_1 与 b_2 一奇一偶。

- 若 b_i 为奇数，则 a_i = 2b_i \equiv 2 \pmod{4}，即 v_2(a_i) = 1；

- 若 b_i 为偶数，则 a_i = 2b_i \equiv 0 \pmod{4}，即 v_2(a_i) \ge 2。

因此两个系数恰好一个模4余2、一个被4整除，2进赋值严格互补。

\blacksquare

3 核心定理二：双素因子梅森合数的阶一致上界

3.1 定理陈述

定理2（双素因子阶一致上界定理） 所有恰含两个不同素因子的梅森合数，其最小非归零阶恒满足

k_p = 3.

换言之，不存在双素因子的双底梅森伪素数，所有双因子合数的斯特林阶均在3阶处破缺。

3.2 严格证明

由系数奇偶互补定理，双素因子梅森合数必有一个素因子的系数 a 被4整除。

根据双底禁型定理，对于系数被4整除的素因子 q，底3的费马同余不成立，即

3^{M_p - 1} \not\equiv 1 \pmod{q}.

因此全局范围内必然有 3^{M_p - 1} \not\equiv 1 \pmod{M_p}。

由阶-底对应定理，这等价于 S(M_p, 3) \not\equiv 0 \pmod{M_p}，即最小非归零阶不超过3。

又因2阶斯特林数对所有梅森数恒归零，故最小非归零阶恰好等于3。

\blacksquare

3.3 纲领意义

这是阶提升纲领启动以来，首个在非平凡子族中得到证明的阶一致上界结果，具有里程碑式的意义：

1. 它从子族层面严格证实了“结构越简单，阶数上限越低”的核心直觉；

2. 它提供了“2进赋值分析 + 禁型定理”的标准化子族攻坚方法，可直接向三因子、四因子等更复杂子族推广；

3. 它为最终的一般情形猜想提供了强支撑——最简单的合数阶数最低，结构越复杂阶数可能越高，但复杂度本身并非无限。

5 向多因子情形的推广展望

双素因子的证明方法可直接推广到固定 k 个素因子的情形，核心仍是2进赋值分析。

三素因子情形的初步分析

对于恰含3个不同素因子的梅森合数，同理代入展开并除以2，可得 b_1 + b_2 + b_3 必须为奇数，即三个 b_i 中有奇数个奇数（1个或3个）。

- 若仅1个 b_i 为奇数，则有2个系数被4整除，同样不满足双底条件，阶数仍为3；

- 若3个 b_i 全为奇数，则所有系数均模4余2，均满足双底必要条件，阶数有可能大于3。

这说明三素因子梅森合数有可能存在双底伪素数，阶上界高于3。但可进一步结合更高阶的禁型定理，推导其阶数的一致上界。这是下一步最直接的攻坚方向。

一般固定k因子情形

对于固定 k 个素因子的梅森合数，通过2进赋值可确定系数2进赋值的分布约束，再结合对应阶数的禁型定理，有望证明其阶数存在仅依赖 k 的一致上界。若该猜想成立，将是向终极目标迈进的一大步。

优先级一：三素因子子族的阶一致上界
