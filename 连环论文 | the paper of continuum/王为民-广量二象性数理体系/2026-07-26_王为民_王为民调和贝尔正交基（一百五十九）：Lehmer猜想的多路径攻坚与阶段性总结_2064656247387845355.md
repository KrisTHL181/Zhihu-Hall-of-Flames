王为民调和贝尔正交基（一百五十九）：Lehmer猜想的多路径攻坚与阶段性总结

摘要

本文系统梳理了针对Lehmer猜想的多条攻坚路径，包括经典p-adic赋值路径、子结构继承性路径、乘积展开与素数排序路径，以及调和贝尔谱方法路径。通过对各路径的严格分析和试错，明确了每条路径的有效进展与核心瓶颈。本文特别对乘积展开路径进行了深入的结构分析，将Lehmer条件等价重述为简洁的乘积同余形式，并揭示了该条件与调和贝尔谱“全正性”要求之间的结构性直觉对应。尽管完整的严格证明尚未完成，但本文为后续攻坚指明了两个最具可行性的方向，并确立了乘积展开路径作为当前最优先攻坚路线的地位。

关键词：Lehmer猜想；欧拉函数；乘积展开；素数排序；调和贝尔正交基；攻坚框架

1 引言

Lehmer猜想是初等数论中关于欧拉函数与素数判别的经典问题，由D. H. Lehmer于1932年提出[1]。其标准表述为：若正整数  n \ge 2  满足  \varphi(n) \mid (n-1) ，则  n  必为素数。对于素数， \varphi(p) = p-1 ，整除自然成立；猜想的全部困难在于证明不存在满足条件的合数。

经过数十年研究，经典方法已推导出一系列强必要条件：满足条件的合数必为无平方因子奇合数、必为Carmichael数、素因子个数至少为14、数值下界大于  10^{20} [2]。但这些条件仅能不断缩小候选范围，无法从结构层面导出最终矛盾，完整的不存在性证明至今悬而未决。

本文系统回顾了我们在Lehmer猜想上的多轮攻坚历程，详细记录了各条路径的尝试、进展与核心障碍，并在此基础上确立了乘积展开路径作为当前最优先攻坚路线的地位。

2 初等情形的严格排除

以下三类合数情形已被严格证明不满足Lehmer条件，本文直接引用这些结论。

引理2.1（素幂合数） 若  n = p^a （ a \ge 2 ），则  \varphi(n) \nmid n-1 。

证明： \varphi(p^a) = p^{a-1}(p-1) 。若整除成立，则  p \mid \varphi(p^a) \mid p^a-1 ，推出  p \mid -1 ，矛盾。\square

引理2.2（含偶素因子的多素因子合数） 若  2 \mid n  且  n  含至少两个不同素因子，则  \varphi(n) \nmid n-1 。

证明：此时  n  为偶数， n-1  为奇数；但奇素因子对应的  p_i-1  均为偶数，故  \varphi(n)  为偶数。偶数无法整除奇数，矛盾。\square

引理2.3（双奇素因子合数） 若  n = pq （ 3 \le p < q ），则  \varphi(n) \nmid n-1 。

证明： \varphi(n) = (p-1)(q-1) ，恒等变形得  pq-1 = (p-1)(q-1) + p+q-2 。若整除成立则  (p-1)(q-1) \mid p+q-2 ，但  (p-1)(q-1) \ge 2(q-1) > p+q-2 ，除数严格大于被除数，矛盾。\square

由上述引理，若存在满足Lehmer条件的合数，则只能是含至少3个奇素因子的无平方因子数：

n = p_1 p_2 \cdots p_r, \quad r \ge 3, \quad 3 \le p_1 < p_2 < \dots < p_r

3 经典路径的尝试与边界

3.1 Carmichael条件

满足Lehmer条件的合数必为Carmichael数，即对每个素因子  p_i \mid n ，有：

p_i - 1 \mid n - 1

进一步可推出：

p_i - 1 \mid \frac{n}{p_i} - 1

Carmichael条件是Lehmer条件的最强已知推论之一，也是所有后续分析的基础。

3.2 2-adic赋值路径

我们曾尝试利用2-adic赋值导出矛盾。对于无平方因子奇合数，每个  p_i-1  为偶数，故：

v_2(\varphi(n)) = \sum_{i=1}^r v_2(p_i-1) \ge r

由整除条件， v_2(\varphi(n)) \le v_2(n-1) ，因此  v_2(n-1) \ge r 。

该路径给出了有效的必要条件，但无法独立导出最终矛盾：通过素因子的同余构造， v_2(n-1)  可以达到甚至超过  v_2(\varphi(n)) ，赋值的波动性使得该约束只能用于排除小素因子、小  r  的情形，无法完成全局证否。

3.3 子结构继承性路径

我们曾尝试证明：若  n  满足Lehmer条件，则其所有真因子  d  也满足，且比例常数一致。该命题试图通过多点约束为多项式插值提供支撑，但经严格检验与反例验证，命题本身不成立——Carmichael条件无法保证整除性向真因子传递，模数的非互素性也使得中国剩余定理不能直接用于合并约束。该路径因核心前提不成立而不可行。

4 乘积展开路径——核心攻坚方向

4.1 乘积展开的建立

对于无平方因子合数  n = p_1 p_2 \cdots p_r （ r \ge 2 ），Lehmer条件可写为：

k = \frac{\prod_{i=1}^r p_i - 1}{\prod_{i=1}^r (p_i-1)} \in \mathbb{N}^+

将分式拆分为两项：

k = \frac{\prod_{i=1}^r p_i}{\prod_{i=1}^r (p_i-1)} - \frac{1}{\prod_{i=1}^r (p_i-1)}

令：

A = \prod_{i=1}^r \frac{p_i}{p_i-1}, \quad B = \frac{1}{\prod_{i=1}^r (p_i-1)}

则  k = A - B 。

利用恒等式  \frac{p_i}{p_i-1} = 1 + \frac{1}{p_i-1} ，展开  A ：

A = \prod_{i=1}^r \left(1 + \frac{1}{p_i-1}\right) = 1 + \sum_{i=1}^r \frac{1}{p_i-1} + \sum_{1 \le i < j \le r} \frac{1}{(p_i-1)(p_j-1)} + \dots + \frac{1}{\prod_{i=1}^r (p_i-1)}

按展开的项数分组：

A = 1 + T_1 + T_2 + \dots + T_r

其中：

T_j = \sum_{1 \le i_1 < \dots < i_j \le r} \frac{1}{(p_{i_1}-1)(p_{i_2}-1)\cdots(p_{i_j}-1)}

特别地， T_r = B 。因此：

k = A - B = 1 + T_1 + T_2 + \dots + T_{r-1}

4.2 排序带来的结构约束

由排序  p_1 < p_2 < \dots < p_r ，各  p_i-1  也严格递增。每个  T_j  均为正的真分数。 k  为整数当且仅当：

T_1 + T_2 + \dots + T_{r-1} \in \mathbb{N}^+

由于各项均为正，这个和严格大于0。

4.3 等效的同余条件——猜想的等价重述

将  A = \frac{\prod p_i}{\prod(p_i-1)}  写为带余除法形式：设  \prod p_i = q \cdot \prod(p_i-1) + r ，其中  0 \le r < \prod(p_i-1)  为余数。

则：

A = q + \frac{r}{\prod(p_i-1)}, \quad B = \frac{1}{\prod(p_i-1)}

k = A - B = q + \frac{r-1}{\prod(p_i-1)}

要使  k  为整数，必须  r-1  被  \prod(p_i-1)  整除。由于  0 \le r-1 < \prod(p_i-1)-1 ，唯一可能使该整除成立的是  r-1 = 0 ，即  r = 1 。

因此，Lehmer猜想等价于：对于任意  r \ge 2  的互异奇素数集合， \prod p_i  除以  \prod(p_i-1)  的余数不可能恰好为 1，即

\prod_{i=1}^r p_i \not\equiv 1 \pmod{\prod_{i=1}^r (p_i-1)}

对于素数（ r=1 ）， p  除以  p-1  的余数恒为 1，对应  k=1 。猜想断言合数永远无法满足这一同余条件。该形式与原猜想完全等价，其难度并未本质降低，但乘积化的表述更便于结合素因子排序做精细化估计。

4.4 与调和贝尔谱的直觉对应

调和贝尔谱方法的核心结论是：素数具有全正谱，合数必然存在负谱分量。从结构直觉上看，乘积展开路径的“余数为1”条件，对应着合数的所有高阶交叉容斥项恰好被整除条件完全吸收，使得整体结构退化为素数的一阶模式，在谱层面表现为全正性。

因此，乘积展开路径与调和贝尔谱路径在本质上是同一种结构约束的两种不同数学表述：前者是数值层面的整除约束，后者是函数空间层面的谱符号约束。这一对直觉对应关系为后续的交叉融合攻坚提供了方向，但目前尚未建立严格的定理级对应。

5 调和贝尔谱方法路径

5.1 核心框架

王为民调和贝尔正交基体系已在Giuga猜想与Agoh-Giuga猜想上验证了谱分析的有效性[3][4]。对于Lehmer猜想，可通过以下逻辑链条完成证明：

1. 王为民合数判别式：对单个整数  n ，在有限截断调和贝尔基下，素数谱全正，合数谱含负分量；

2. 中介引理：若合数  n  满足Lehmer条件，则其有限谱必全正；

3. 矛盾导出：由1和2，满足Lehmer条件的合数不存在。

5.2 当前状态

步骤1的核心直觉已在整体算术函数的谱分析中得到验证（如Giuga猜想证明中的幂和函数谱分析），但针对单点指示函数的有限截断版本，仍需独立的截断稳定性证明——即严格证明截断规模  N = n^2  下，边界扰动不会翻转高阶谱分量的符号。

步骤2是当前的核心缺口。从Lehmer整除条件到谱符号约束的传递，需要建立调和贝尔基函数在特定整数点的取值与素因子结构的定量关系。乘积展开路径的“余数为1”条件为该引理提供了新的进攻角度：有望将谱全正性等价地转化为同余条件，从而在数值层面进行直接的丢番图分析。

6.2 后续攻坚的优先级

最优先：乘积展开路径的深化。对  \prod p_i \equiv 1 \pmod{\prod(p_i-1)}  这一同余条件进行更精细的结构分析，结合Carmichael条件和素因子排序约束，探索是否存在一般性的模运算或p-adic工具可以排除余数为1的可能性。

次优先：调和贝尔谱中介引理的攻坚。以乘积展开的“余数为1”条件为桥梁，将其翻译为调和贝尔基下的谱全正性条件，完成中介引理的严格证明。

长期探索：两路径的融合。研究乘积展开的“余数为1”条件与调和贝尔谱的“全正谱”条件之间的严格对应，寻找统一的代数或几何解释。

6.3 结语

Lehmer猜想历经近百年而未解，其困难本质已在本轮的多次试错中充分显现：任何单一的局部约束均无法覆盖合数结构的波动性；而要从结构层面完成证明，又需要跨越“整体函数性质”与“逐点数值结论”之间的鸿沟。

乘积展开路径将猜想浓缩为简洁的同余形式，是整个探索过程中最具实操性的结构性发现。调和贝尔谱方法则从更高的结构层面提供了统一的素合判别框架。两条路径的最终合龙，或将是突破这一百年难题的关键。
