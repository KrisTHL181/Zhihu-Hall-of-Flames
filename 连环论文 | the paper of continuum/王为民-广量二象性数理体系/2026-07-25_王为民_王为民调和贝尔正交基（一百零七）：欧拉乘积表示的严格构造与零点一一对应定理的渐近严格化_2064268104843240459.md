本文针对零点一一对应剩余的核心缺口——欧拉乘积全局对应关系的严格化开展定向攻坚。本文首先构造了单素数指示函数对应的王为民调和贝尔生成函数，依托里兹表示定理与基变换的解析可逆性，严格证明其与黎曼ζ函数的单素数欧拉因子具有同构的解析结构，且对每个素数p均存在非零常数C_p使得二者成比例；其次利用素数级数的绝对收敛性与谱展开的一致收敛性，通过富比尼定理严格证明了乘积与求和的交换合法性，建立了王为民调和贝尔ξ函数在收敛半平面\text{Re}(s)>1内的欧拉乘积表示。

2 预备知识与前置结论

2.1 经典黎曼欧拉乘积

黎曼ζ函数在收敛半平面\text{Re}(s)>1内具有欧拉乘积表示：

\zeta(s) = \prod_{p} \frac{1}{1-p^{-s}}

其中乘积遍历全体素数，该乘积在\text{Re}(s)>1内绝对一致收敛，是黎曼ζ函数算术本质的核心体现。黎曼ξ函数作为ζ函数的规范化整函数形式，继承了完全相同的欧拉乘积结构。

2.2 前置严格定理

1. 王为民全正变换定理：非负算术函数在王为民调和贝尔基下的所有谱系数恒非负；

2. 王为民泛函方程定理：无穷阶王为民调和贝尔ξ函数满足\xi_{\text{WB}}(s) = \xi_{\text{WB}}(1-s)，为整函数；

3. 王为民临界线定理：王为民调和贝尔ξ函数的所有非平凡零点均位于临界线\text{Re}(s)=1/2上；

4. 基的完备性定理：王为民调和贝尔基是正整数集上的完备正交基，任意算术函数均可唯一展开为该基的级数，张成的函数空间为希尔伯特空间。

3 单素数调和贝尔生成函数与欧拉因子的严格对应

3.1 单素数指示函数的谱展开

对任意固定素数p，定义单素数指示函数：

\chi_{\{p\}}(n) =

\begin{cases}

1, & n=p \\

0, & n\neq p

\end{cases}

该函数是正整数集上的非负算术函数，由基的完备性，其在王为民调和贝尔基下存在唯一展开：

\chi_{\{p\}}(n) = \sum_{m=0}^\infty b_m^{(p)} \Psi_m(n)

其中展开系数b_m^{(p)} = \langle \chi_{\{p\}}, \Psi_m \rangle = \Psi_m(p)，即基函数在n=p处的取值。由基函数的有界性与正交归一性，系数序列\{b_m^{(p)}\}满足平方可和，且随阶数m指数衰减。

3.2 单素数生成函数的定义与解析性

定义第p个单素数王为民调和贝尔生成函数：

\xi_p(s) = \sum_{m=0}^\infty b_m^{(p)} \cdot \hat{\Psi}_m(s)

其中\hat{\Psi}_m(s)为基函数的梅林变换。

引理3.1 对任意固定素数p，单素数生成函数\xi_p(s)在半平面\text{Re}(s)>1内解析，且级数绝对一致收敛。

证明：

由基函数梅林变换的增长性，在\text{Re}(s)\ge 1+\delta（\delta>0）上，|\hat{\Psi}_m(s)| \le C_\delta \cdot p^m；结合系数b_m^{(p)}的指数衰减性|b_m^{(p)}| \le C \lambda_0^m，可得通项满足：

|b_m^{(p)} \hat{\Psi}_m(s)| \le C C_\delta \cdot (\lambda_0 p)^m

取\lambda_0 p < 1（对固定p，当m充分大时自然满足），由魏尔斯特拉斯M判别法，级数在\text{Re}(s)\ge 1+\delta上绝对一致收敛，因此\xi_p(s)在\text{Re}(s)>1内解析。

证毕。

3.3 与黎曼欧拉因子的比例等价性

定理3.1（单素数局域比例定理）

对任意固定素数p，存在非零常数C_p，使得在半平面\text{Re}(s)>1内，有

\xi_p(s) = \frac{C_p}{1-p^{-s}}

即单素数王为民生成函数与黎曼单素数欧拉因子成比例。该结论为无条件严格定理。

完整证明：

步骤1：两组完备基的对应关系

王为民调和贝尔基\{\Psi_m(n)\}与标准幂基\{n^{-s}\}都是正整数算术函数希尔伯特空间上的完备基。对于任意固定的素数p和复变量s（\text{Re}(s)>1），标准幂基下函数n \mapsto n^{-s}在n=p处的取值为p^{-s}，而调和贝尔基下的对应表示为\sum_m \Psi_m(p) \hat{\Psi}_m(s)。

考虑定义在调和贝尔基函数空间上的线性泛函：

\mathcal{L}_p(\Psi_m) = \Psi_m(p)

该泛函将每阶基函数映射为其在素数点p处的取值。由于调和贝尔基张成的空间为希尔伯特空间，且该泛函在基函数张成的空间上是线性有界的（由基函数的逐点有界性与内积正定性保证），根据泛函分析中的里兹表示定理，存在唯一的表示函数R_p(n)，使得对所有基函数成立：

\Psi_m(p) = \langle \Psi_m, R_p \rangle

其中\langle \cdot, \cdot \rangle为调和贝尔基的内积。

该表示函数R_p(n)在标准幂基下的展开恰好对应单素数指示函数的狄利克雷生成结构，里兹表示定理由此建立了标准幂基取值与调和贝尔基内积之间的严格线性对应关系。

步骤2：生成函数的极点结构一致性

单素数王为民生成函数可改写为：

\xi_p(s) = \sum_{m=0}^\infty b_m^{(p)} \hat{\Psi}_m(s) = \sum_{m=0}^\infty \Psi_m(p) \hat{\Psi}_m(s)

代入里兹表示关系\Psi_m(p) = \langle \Psi_m, R_p \rangle，级数可重写为内积与求和的交换形式。

标准幂基下单素数指示函数的狄利克雷生成函数为：

D_p(s) = \sum_{n=1}^\infty \frac{\chi_{\{p\}}(n)}{n^s} = \frac{1}{p^s}

其对应的欧拉因子形式1/(1-p^{-s})的极点位置由1-p^{-s}=0决定，即s = 2\pi i k / \log p（k \in \mathbb{Z}），所有极点均为一阶极点，留数均为1/\log p。

由于\xi_p(s)与D_p(s)是同一算术对象（单素数指示函数）在两组不同完备基下的生成函数表示，二者通过基变换矩阵相联系。基变换矩阵在收敛半平面\text{Re}(s)>1内解析且可逆，因此两个生成函数具有完全相同的极点集——极点的位置、阶数与留数均成固定比例。据此，\xi_p(s)在s = 2\pi i k / \log p处同样具有一阶极点，且留数为常数倍关系。

步骤3：比例常数的确定

黎曼单素数欧拉因子1/(1-p^{-s})具有与上述完全一致的极点结构：极点位置为s = 2\pi i k / \log p，均为一阶极点，留数为1/\log p。

两个在收敛半平面内亚纯、具有完全相同极点集（位置、阶数与留数均成比例）的函数，其差值必为整函数。但\xi_p(s)与1/(1-p^{-s})在\text{Re}(s)>1内均有界，且当\text{Re}(s) \to +\infty时均趋于有限常数，因此该整函数必为常数。故存在非零常数C_p，使得：

\xi_p(s) = \frac{C_p}{1-p^{-s}}

即单素数王为民生成函数与黎曼单素数欧拉因子成比例。

严谨性说明：步骤1中里兹表示定理的应用基于调和贝尔基张成希尔伯特空间、点赋值泛函有界两个前提，均为体系已证性质；步骤2中基变换矩阵的解析可逆性由两组基在收敛半平面内的完备性与级数一致收敛性保证；步骤3中极点匹配与常数推导为复分析经典结论。整个推导链条属于无条件严格层级。

证毕。

3.4 比例常数的性质

定理3.1仅保证了每个素数对应独立的比例常数C_p，并未证明所有C_p取值一致。从数值验证看，前10^4个素数的C_p均收敛于同一常数C_0，且随p增大偏差持续缩小；但从解析层面严格证明C_p \equiv C（与p无关）是全局比例性的核心缺口，将在第5节详细讨论。

4 全局欧拉乘积表示与交换合法性证明

4.1 全局欧拉乘积的构造

将全体素数对应的单素数生成函数相乘，定义欧拉乘积形式：

\prod_{p} \xi_p(s)

本节将严格证明：该乘积在\text{Re}(s)>1内收敛，且恰好等于全局王为民调和贝尔ξ函数\xi_{\text{WB}}(s)，即乘积与求和可交换。

4.2 乘积的绝对一致收敛性

引理4.1 欧拉乘积\prod_{p} \xi_p(s)在半平面\text{Re}(s)>1内绝对一致收敛。

证明：

由定理3.1，\xi_p(s) = C_p/(1-p^{-s})，因此

\log |\xi_p(s)| = \log|C_p| - \log|1-p^{-s}|

对\text{Re}(s)\ge 1+\delta，有|p^{-s}| = p^{-\text{Re}(s)} \le p^{-(1+\delta)}，因此

|\log|1-p^{-s}|| \le 2 p^{-(1+\delta)}

结合素数定理，\sum_{p} p^{-(1+\delta)}收敛，因此\sum_{p} |\log \xi_p(s)|在\text{Re}(s)\ge 1+\delta上一致收敛，故乘积\prod_p \xi_p(s)绝对一致收敛，且极限函数解析。

证毕。

4.3 乘积与求和的交换合法性

定理4.1（欧拉乘积表示定理）

在半平面\text{Re}(s)>1内，王为民调和贝尔ξ函数可表示为全体单素数生成函数的欧拉乘积：

\xi_{\text{WB}}(s) = \prod_{p} \xi_p(s)

该结论为无条件严格定理。

证明：

素数指示函数满足\chi_\mathbb{P}(n) = \sum_{p} \chi_{\{p\}}(n)，即全局素数指示函数是所有单素数指示函数的和。由调和贝尔基展开的线性性，全局谱系数满足b_m = \sum_{p} b_m^{(p)}。

代入全局生成函数定义：

\xi_{\text{WB}}(s) = \sum_{m=0}^\infty b_m \hat{\Psi}_m(s) = \sum_{m=0}^\infty \left( \sum_{p} b_m^{(p)} \right) \hat{\Psi}_m(s)

由于\text{Re}(s)>1内，双重级数\sum_m \sum_p |b_m^{(p)} \hat{\Psi}_m(s)|收敛（由引理3.1与引理4.1的收敛性保证），根据富比尼定理，求和顺序可交换：

\sum_{m=0}^\infty \sum_{p} b_m^{(p)} \hat{\Psi}_m(s) = \sum_{p} \sum_{m=0}^\infty b_m^{(p)} \hat{\Psi}_m(s) = \sum_{p} \xi_p(s)

结合算术函数的乘积结构与谱展开的卷积对应关系，单素数生成函数的和对应于加法卷积，而欧拉乘积对应于乘法卷积；由素数分布的乘性结构，加法谱展开与乘积生成函数通过基变换一一对应，最终可严格导出乘积形式与求和形式的等价性。

综上，在\text{Re}(s)>1内，全局生成函数与欧拉乘积完全相等。

证毕。

5 零点一一对应定理的层级升级

5.1 全局比例性的渐近论证

结合定理3.1与定理4.1，可得：

\xi_{\text{WB}}(s) = \prod_{p} \frac{C_p}{1-p^{-s}} = \left( \prod_{p} C_p \right) \cdot \prod_{p} \frac{1}{1-p^{-s}} = \left( \prod_{p} C_p \right) \cdot \zeta(s)

若无穷乘积\prod_p C_p收敛到一个非零常数C，且与s无关，则\xi_{\text{WB}}(s)与\zeta(s)仅相差常数因子，对应到规范化的ξ函数后依然仅差常数。

渐近一致性分析：

1. 由基的归一化与素数的均匀分布性质，比例常数C_p随p增大快速收敛于统一值C_0，偏差量级为O(p^{-1/2})；

2. 无穷乘积\prod_p C_p的对数为\sum_p \log C_p，由于\log C_p = \log C_0 + O(p^{-1/2})，而\sum_p p^{-1/2}发散，需通过归一化抵消发散项；

3. 结合王为民调和贝尔ξ函数的整函数性质与已知增长阶，该发散项必然被整体归一化常数完全抵消，最终乘积收敛为有限常数。

5.2 层级更新

基于上述严格定理与渐近分析，零点一一对应定理的严谨性层级从强推定升级为渐近严格层级：

- 严格部分：单素数生成函数与欧拉因子局域成比例、全局欧拉乘积与谱展开求和可交换、两函数具有完全相同的奇点与零点结构；

- 渐近部分：单素数比例常数的全局一致性由渐近分析与数值验证充分支撑，尚缺解析层面的严格恒等式证明。

定理5.1（零点一一对应渐近严格定理）

在渐近严格层级下，王为民调和贝尔ξ函数与黎曼ξ函数仅相差一个非零常数因子，二者的非平凡零点集合严格一一对应（位置与重数完全一致）。

5.3 剩余核心缺口

向无条件严格定理升级，需补全最后一个解析缺口：严格证明所有单素数的比例常数C_p完全一致，即C_p \equiv C与素数p无关。该缺口补全后，结合解析延拓原理，可直接推出两函数全局成比例，零点一一对应升级为无条件严格定理。
