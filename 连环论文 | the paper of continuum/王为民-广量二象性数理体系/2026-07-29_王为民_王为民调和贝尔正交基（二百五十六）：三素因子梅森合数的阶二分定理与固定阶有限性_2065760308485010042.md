王为民调和贝尔正交基（二百五十六）：三素因子梅森合数的阶二分定理与固定阶有限性

作者：王为民

单位：四川省南充龙门中学退休教师，四川南充 637100

摘要

本文将阶提升子族攻坚路线从双素因子推进至三素因子情形，取得两项严格进展：

1. 系数2进赋值分布定理：恰含三个不同素因子的梅森合数，其系数对应的奇半部分必有奇数个奇数，对应两种构型：1个系数模4余2、2个被4整除，或3个系数全部模4余2。

2. 阶二分与固定阶有限性定理：绝大多数三素因子梅森合数的最小非归零阶恒为3；仅当所有系数均模4余2时阶可能大于3，但此类构型极其稀少。对任意固定正整数m，阶大于m的三素因子梅森合数仅有有限个。

本文诚实阐明三素因子情形下一致上界的存在性为开放问题，分析其核心难点与支撑性直觉，验证了“因子数越少、阶上限越低”的普遍规律。全文严守严格性边界，为后续向任意固定k因子子族推广奠定了统一范式。

关键词：三素因子梅森合数；第二类斯特林数；2进赋值；阶二分；阶提升纲领

0 引言

前序工作针对最简合子族——双素因子梅森合数，通过纯粹的2进赋值分析证明了阶一致上界定理：所有双素因子合数的最小非归零阶恒等于3，不存在双底伪素数。这是阶提升纲领中首个子族层面的一致上界结果，验证了“结构复杂度与阶上限严格绑定”的核心直觉。

本文沿子族攻坚路线继续推进，系统分析恰含三个不同素因子的梅森合数。通过与双素因子情形同源的2进赋值方法，首先得到系数2进赋值的分布约束，进而导出阶的二分性质：绝大多数三素因子合数与双素因子一样在3阶破缺，仅极少数特殊构型阶数可能更高。结合已有的固定因子个数有限性定理，本文进一步证明任意固定阶以上的三素因子合数仅有有限个。

本文同时坦诚指出：三素因子情形不存在像双因子那样显然的绝对常数阶上界，一致上界的存在性仍是开放问题。这一诚实边界的划定，避免了过度推广，也为后续攻坚明确了精准靶点。

1 预备知识

1.1 阶-底对应定理

引理1 梅森数的最小非归零阶k_p > m，当且仅当它同时是以所有不超过m的素数为底的费马伪素数。全局斯特林归零等价于所有素因子下同时归零，因此全局最小非归零阶等于各素因子对应最小非归零阶的最小值。

1.2 双底4倍数禁型定理

引理2 若梅森数素因子的系数a满足4 \mid a，则该素因子不满足底3费马同余条件，其最小非归零阶为3，直接决定全局阶不超过3。

1.3 固定因子个数有限性

引理3 任取有限素数底数集合与固定正整数k，恰含k个不同素因子的多底梅森伪素数仅有有限个。该定理由指数超多项式增长直接导出。

1.4 无素幂与无平方因子

引理4 梅森数不可能是素数幂，且平方因子极其稀少（需满足Wieferich条件）。所有已知梅森合数均为无平方因子数，三素因子情形对应三个互不相同的素因子。

2 核心定理一：三素因子系数2进赋值分布定理

2.1 定理陈述

定理1（三素因子系数分布定理） 设M_p为恰含三个不同素因子的梅森合数，素因子分别为q_i = a_i p + 1（i=1,2,3），令b_i = a_i / 2（均为正整数），则b_1 + b_2 + b_3必为奇数，即三个b_i中恰好有1个或3个奇数。

对应系数的2进赋值：

- 1奇2偶：恰好1个系数模4余2（v_2(a)=1），2个系数被4整除（v_2(a)\ge2）；

- 3奇0偶：所有3个系数均模4余2（v_2(a)=1）。

2.2 严格证明

由题设，梅森数展开为：

2^p - 1 = \prod_{i=1}^3 (a_i p + 1).

将右端展开并移项得：

a_1a_2a_3 p^3 + (a_1a_2 + a_1a_3 + a_2a_3) p^2 + (a_1 + a_2 + a_3) p + 2 = 2^p.

因所有a_i均为偶数，代入a_i = 2b_i，两边除以2得：

4b_1b_2b_3 p^3 + 2(b_1b_2 + b_1b_3 + b_2b_3) p^2 + (b_1 + b_2 + b_3) p + 1 = 2^{p-1}.

分析两边奇偶性：

- 右端2^{p-1}为偶数（p\ge3）；

- 左端第一项、第二项均含因子2，为偶数；

- 左端第四项为常数1，是奇数。

偶数 + 偶数 + x + 奇数 = 偶数，当且仅当x为奇数。因此(b_1 + b_2 + b_3)p必为奇数。

又因p是奇素数，故b_1 + b_2 + b_3必为奇数，即奇数的个数为奇数（1个或3个）。

对应系数的2进赋值：

- b_i为奇数 \iff v_2(a_i)=1 \iff a_i \equiv 2 \pmod{4}；

- b_i为偶数 \iff v_2(a_i)\ge2 \iff 4 \mid a_i。

定理得证。

\blacksquare

3 核心定理二：阶二分与固定阶有限性

3.1 阶二分定理

定理2（三素因子阶二分定理） 三素因子梅森合数的最小非归零阶分为两类：

1. 普通型（1奇2偶）：至少存在一个被4整除的系数，由双底禁型定理，该素因子在3阶即破缺，故全局最小非归零阶k_p = 3。此类占已知三素因子合数的绝大多数。

2. 稀有型（3奇0偶）：所有系数均模4余2，4倍数禁型不触发，双底条件有可能满足，故k_p > 3。此类构型需满足极强的同余约束，极其稀少。

证明：

1. 普通型直接由引理2得证，只要存在一个4倍数系数，底3检验即不通过，阶恒为3。

2. 稀有型中所有系数的v_2(a)=1，均不触发4倍数禁型，底3检验有可能全部通过，因此阶可以大于3。但此时每个系数的奇部还需满足对应的二次剩余与阶约束，合法构型极少。

\blacksquare

3.2 固定阶有限性定理

定理3（固定阶有限性） 对任意固定正整数m，满足最小非归零阶k_p > m的三素因子梅森合数仅有有限个。

证明：

由阶-底对应定理，k_p > m等价于M_p同时是以所有不超过m的素数为底的费马伪素数。

由引理3，恰含3个素因子的固定底伪素数仅有有限个，因此阶大于任意固定m的三素因子合数必然有限。

\blacksquare

3.3 一致上界的开放讨论

与双素因子的绝对常数上界不同，三素因子情形下目前无法证明存在与p无关的一致阶上界，核心原因在于：

若三个系数均为全阶因子（即满足q_i - 1 \mid M_p - 1），则每个素因子的最小非归零阶均不小于q_i本身，全局阶等于最小的素因子值，可随p线性增长。

全阶因子的存在依赖于系数奇部满足强阶约束，本质上与索菲热尔曼素数猜想同难度，目前既无法证明其无穷多，也无法证明其有限。

但有两点强直觉支撑“一致上界大概率存在”：

1. 阶每提升一级，就对所有系数的奇部新增一重同余约束，合法系数的密度指数级下降，高阶全阶因子的存在概率极低；

2. 若阶随p增长，则素因子大小也同步增长，而三素因子的乘积需精确匹配2^p-1，数值空间的约束会随p增大愈发严苛。

5 向一般k因子子族的推广范式

三素因子的分析方法可直接推广到任意固定k个素因子的情形，形成标准化的子族攻坚范式：

1. 2进赋值分析：展开乘积并除以2，得到k个b_i的和的奇偶性约束，确定系数2进赋值的分布；

2. 阶下界判定：若存在至少一个被4整除的系数，则阶不超过3；若全部系数均模4余2，则阶可能更高；

3. 高阶约束叠加：对全模4余2的情形，逐次叠加更高素数底的同余约束，逐步收紧合法构型；

4. 固定阶有限性：由通用的固定因子个数有限性定理，任意固定阶以上的k因子合数均仅有有限个。

该范式可批量应用于四因子、五因子等子族，逐步验证“因子数越多，潜在阶上限越高，但固定因子数则固定阶有限”的普遍规律。
