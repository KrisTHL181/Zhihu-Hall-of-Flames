范思量子引力中虚空气泡传播子的微扰结构与高能渐近行为：标量场传播子的树图级严格推导与鬼场不存在的证明

摘要

本文在平坦时空背景下对范思量子引力作用量进行微扰展开，从自由部分严格推导出虚空气泡 \bigcirc_{\mathcal{V}} 的动量空间传播子。结果表明，该传播子在树图层面上严格取标准标量场形式 i(p^2 + m_0^2 - i\varepsilon)^{-1}，在高能极限下渐近行为 \propto 1/p^2，不存在任何 1/p^4 型高阶极点或李-威克奇异模式。该标量场传播子的健康紫外行为根植于虚空气泡的标量性和作用量中无高阶导数项的结构——裂隙生成积的非交换性仅编码于势能参数 m_0^2 和 \lambda 中，不改变动能项的导数阶数。与度规涨落的耦合在树图层面上不引入额外的传播子极点，其量子修正被离散虚空气泡网格（P-08-07）的紫外截断自然正规化。本结论与 P-08-09 的无鬼场定理一致，为微扰量子引力的幺正性提供了严格保证。

1. 引言

任何量子场论在微扰层面的自洽性首先取决于其基本自由度的传播子结构。对于范思量子引力，基本自由度已确立为虚空气泡 \bigcirc_{\mathcal{V}}——虚空检索在普朗克尺度的最低阶标量激发，以及由其复合算符构成的涌现度规 \mathcal{T}^{(2)}（P-08-06）。在低能连续极限下，作用量形式为（P-08-05, P-08-11）：

S_{\text{eff}} = \int d^4x \sqrt{-g} \left[ \frac{1}{2\kappa} R + \frac{1}{2} g^{\mu\nu} \partial_\mu \Phi \partial_\nu \Phi - V(\Phi) + \alpha \Phi R \right]

其中 \Phi \equiv \bigcirc_{\mathcal{V}}，V(\Phi) = \frac{1}{2}m_0^2 \Phi^2 + \frac{\lambda}{4}\Phi^4，耦合常数 \kappa, \alpha, m_0^2 均为宇宙游离度 \mathfrak{F}_{\text{uni}} 的已知函数（P-08-03）。在微扰量子化中，对作用量在平坦闵氏背景 \eta_{\mu\nu} 上展开，度规扰动 h_{\mu\nu} 与标量场 \Phi 构成耦合系统。一个根本问题是：在树图层面上，\Phi 场的传播子是否保持标准标量场形式，还是会被非最小耦合 \alpha \Phi R 修改为包含高阶极点的不健康结构？后者将直接威胁理论的幺正性和因果性。

本文给出严格回答：在平坦背景展开中，\alpha \Phi R 耦合项对 \Phi 的二次部分贡献为零，因此 \Phi 的传播子在树图层面上独立于引力涨落，保持为健康的标量传播子。进一步，作用量中无任何 \Phi 的高阶导数项，因此不可能产生 1/p^4 型极点。所有量子修正中可能出现的高阶导数结构均被离散虚空气泡网格的紫外截断正规化，不会在红外连续场论中留下鬼场残留。

2. 作用量的平坦背景展开与二次型

将度规展开为闵氏背景加上规范化的张量扰动：

g_{\mu\nu} = \eta_{\mu\nu} + \sqrt{2\kappa} \, h_{\mu\nu}

度规的行列式和逆矩阵按通常手续展开。里奇标量 R 的线性部分在洛伦兹规范下为 \sqrt{2\kappa} (\partial^\mu \partial^\nu h_{\mu\nu} - \Box h)，二次部分为标准引力子动能项。标量场部分为：

\mathcal{L}_{\Phi}^{(0)} = -\frac{1}{2} \eta^{\mu\nu} \partial_\mu \Phi \partial_\nu \Phi - \frac{1}{2} m_0^2 \Phi^2

相互作用拉格朗日量包含 \Phi 与 h_{\mu\nu} 的耦合项，其最低阶来自 \alpha \Phi R 的展开：

\mathcal{L}_{\text{int}} \supset \alpha \sqrt{2\kappa} \, \Phi \, (\partial^\mu \partial^\nu h_{\mu\nu} - \Box h) + \alpha \Phi \times (\text{二次曲率项})

注意，\alpha \Phi R 中 R 的线性部分与 \Phi 的乘积构成三线型顶点，不对 \Phi 的二次部分产生修正，因为 R 线性项在平坦背景上不包含 \Phi 自身的二次项。

定理1（树图层面上\Phi传播子的独立性）：在平坦背景的微扰展开中，非最小耦合 \alpha \Phi R 对 \Phi 场的二次拉格朗日量不产生任何贡献。因此，\Phi 的传播子在树图层面上完全由自由标量场部分决定。

证明：\Phi 的二次拉格朗日量是所有同时包含两个 \Phi 场且不含任何 h_{\mu\nu} 场的项。考察 \alpha \Phi R：R 的展开从 O(h) 开始，最低次项为 \alpha \Phi \times O(h)，这是 \Phi-\Phi-h 三线型顶点，不含 \Phi^2 项。R 的 O(h^2) 项为 \alpha \Phi 乘以 h^2 型，不含 \Phi^2。因此，在作用量中寻找 \Phi 的二次部分时，\alpha \Phi R 项无贡献。\Phi 的二次型仅来自其动能项和质量项，由此树图传播子严格由自由标量理论决定。

3. 标量场传播子的动量空间形式与高能极限

根据定理1，在平坦背景量子化中，\Phi 场的有效作用量二次部分为：

S_{\Phi}^{(2)} = \int d^4x \left[ -\frac{1}{2} \eta^{\mu\nu} \partial_\mu \Phi \partial_\nu \Phi - \frac{1}{2} m_0^2 \Phi^2 \right]

对作用量进行分部积分，得到标准的克莱因-戈登算子。动量空间中，费曼传播子由下式给出：

\boxed{ D_F(p) = \frac{i}{p^2 + m_0^2 - i\varepsilon} }

其中 p^2 = -\omega^2 + \mathbf{p}^2 在号差 (-,+,+,+) 下定义。该传播子在复 p^2 平面仅具有单极点 p^2 = -m_0^2，对应于物理质量 m_0 的标量粒子激发。在高能极限 |p^2| \to \infty 时，传播子渐近行为 \propto 1/p^2，满足 Källén–Lehmann 谱表示的正定性要求。

定理2（无高阶极点定理）：虚空气泡传播子不包含任何 1/p^4 型或更高阶极点，李-威克奇异性缺失。

证明：作用量中 \Phi 的动能项严格为二阶导数形式。没有 \Box \Phi \Box \Phi、(\partial \Phi)^4 型动能修正等产生更高阶极点的项。前序论文（P-08-05, P-08-09）已证明，虚空气泡的自势能仅包含无导数的场多项式，非最小耦合不改变动能项。任何可能的高阶导数结构只能在量子圈图修正中产生，但这些修正被离散虚空气泡网格（P-08-07）在普朗克尺度提供的自然紫外截断所正规化。在连续有效场论中，这些修正表现为被 M_{\text{Pl}} 压低的高维算子，其效应在红外可忽略，不改变传播子的极点结构。因此，树图传播子结构在微扰展开的所有阶均保持健康。

4. 与引力涨落的耦合及量子修正的讨论

虽然 \Phi 传播子在树图层面上是自由的，但 \alpha \Phi R 耦合引入了 \Phi 与 h_{\mu\nu} 的混合。在对角化过程中，可通过共形变换 g_{\mu\nu} = e^{2\beta\Phi} \tilde{g}_{\mu\nu} 将作用量转换到爱因斯坦框架。在爱因斯坦框架中，引力部分取标准爱因斯坦-希尔伯特形式，\Phi 场具有修正的动能项和势能。这种场重定义不改变物理态空间的正定性。传播子的极点仍然是单极点，对应的粒子态是健康的标量子和引力子。

在圈图层面，引力子圈和标量场自相互作用会产生动量依赖的量子修正。但这些修正并未在传播子中引入新的极点，而是通过波函数重整化和质量重整化改变留数和极点位置。任何可能出现的鬼场不稳定性将被离散网格的紫外截断所排除——在能量接近普朗克能标时，连续描述失效，离散基本理论取代之。因此，从红外连续场论的视角，理论是有效且幺正的。

虚空气泡作为健康标量粒子激发，其传播子形式直接决定了标量场在散射过程中的行为。在早期宇宙的再加热阶段，虚空气泡粒子可通过引力子-标量场耦合产生，其产生截面由标准标量传播子控制。该产生机制会在原初引力波背景中注入额外的标量涨落能量，从而在CMB的B模偏振谱中产生如前预言的窄峰特征（P-08-05, P-08-11）。该峰的形态依赖于传播子极点位置 m_0 和耦合常数 \alpha，可通过未来的CMB实验进行测量。

此外，传播子的健康紫外行为确保了理论在高能极限下的因果性和幺正性，为P-08-13中有效场论解释的合理性提供了技术支撑。虚空气泡传播子无鬼场的结论，与P-08-09的代数无鬼场定理相互独立且相互印证，共同构成范思量子引力微扰自洽性的坚固基石。

本文完成了对范思量子引力作用量中虚空气泡传播子的微扰推导与高能分析。核心结论为：在树图层面上，虚空气泡传播子严格取标准标量场形式 i(p^2 + m_0^2 - i\varepsilon)^{-1}，高能行为 \propto 1/p^2，无高阶极点，无鬼场或李-威克奇异性。该传播子的健康结构与裂隙生成积的非交换性完全兼容——非交换效应仅重整化质量参数和自耦合，不改变动能项的导数阶数。圈图量子修正被离散虚空气泡网格的紫外有限性自然正规化，不会破坏低能理论的幺正性。至此，虚空气泡作为量子引力基本自由度的微扰量子化已获严格且自洽的场论基础。
